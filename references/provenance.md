# Provenance

The methods in ning-stack are adapted from the pinned upstream skills below and restated in this skill's own files; the upstream files are not shipped or loaded at runtime. Read this file when updating the stack, auditing what was kept, or answering where a method came from.

Dispositions: **Adopted** (the method's core is kept), **Partial** (selected parts kept, the rest excluded with a reason), **Conditional** (kept, loaded only under its trigger). Locations are relative to `references/` unless they start with `SKILL.md` or `scripts/`. All three upstream repositories are MIT licensed; their notices are in `LICENSES/`.

## Not adopted

- Cursor-specific mechanics: model slugs, `subagent_type` values, `pstack-models.mdc` role lines, cloud workers, transcript directory layouts, and plugin skills such as unslop, deslop, control-ui and Comment Sicko.
- Matt's `/setup-matt-pocock-skills` configuration and triage label vocabulary; the project's own tracker conventions supply those facts.
- tstack's `pr-wait` script and Monitor-based waiting; ning-stack waits on harness events and never runs polling loops or watcher agents.
- Default fan-outs: two parallel review sub-agents per round, seven why investigators, three reflect reviewers, mandatory arena for implementation. Each became a single-agent default with a conditional escalation.
- Upstream entries marked `disable-model-invocation` are neither invoked nor read at runtime; their methods are restated here with attribution.
